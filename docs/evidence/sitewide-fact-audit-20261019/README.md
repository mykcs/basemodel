## 已证实并修正的来源问题

**MiniMax M2.7 官方发布时间来源。** `src/content/models/minimax-m2-7.json` 将第三方 `apisrouter.com/minimax-m2-7-release-date` 错标为 `official_announcement`，而该链接在本轮返回 **404**。现在替换为 MiniMax 自己的 2026-03-18 官方公告 `https://www.minimax.cn/news/minimax-m27-zh`，保持已有发布日期，不重新推断开放性、授权、性能或 checkpoint 身份；同步更新证据说明、复核日期和确定性 Source ID。这个修复有真实发行方一手信息，而非换一个看似能打开的第三方网页。

另两条在 HTTP 扫描中返回 403 的旧 OpenAI 链接：`https://help.openai.com/en/articles/9624314-model-release-notes` 和 `https://openai.com/index/introducing-gpt-4-5/`。目前只标记「自动访问未证实」，**不把 HTTP 403 等同于内容不存在或产品已撤销**，不擅自改历史 GPT-4.5 事实。
