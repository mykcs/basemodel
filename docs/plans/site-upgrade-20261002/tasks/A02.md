## 代码步骤

1. 选静态文章、Flow、Compare、Workspace、Landscape，记录实际首屏 JS/CSS、请求、加载链、无 JS 内容与操作状态。依赖包大小不等于页面负载。
2. 仅将没有交互职责的 wrapper 迁移为 Astro/HTML。保留需要状态的 Compare/Workspace，不为零 JS 删功能。
3. 图表大模块使用现有按需 import 或合适的 client:visible/idle。第一次点击期间有可访问的加载/失败反馈，不能可点却无响应。
4. 预渲染 figure/table/summary。C02 的静态图、读数和结论不依赖客户端或第三方在线；失败时仍有有用内容。
5. 保留深链接、后退、focus、亮暗、中文及旧英文 redirects。容器稳定尺寸防布局跳动，不能用巨大空白骗首屏预算。
6. 只有被证明重复且不再需要的依赖才移除；lockfile 与 A01 串行。架构取舍落入现有 Dev，保留现有技术栈也是有效结论。

执行 verify:payload、static-first、Compare/Workspace 与相关 UI tests。反例：JS 关闭、第三方离线、慢网络首点、客户端加载失败、刷新深链接、键盘、放大、手机、亮暗。构建成功不等于操作成功。
