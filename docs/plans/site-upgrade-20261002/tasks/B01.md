第一次来的读者理解问题和研究对象；同实验室同伴讲清目前证据与不确定性；几个月后的自己找回上次判断和现在改变了什么。不能要求先学会站内分类。

不另建契约、导航或 mission store。X783 负责 Models/Papers/Compare/Workspace 里的桥接，本任务只拥有进入这些表面的路径。已合并 #781/#782 的进程图和阅读合同直接复用。

## 实施步骤

1. 在现有路由清单标注 primaryTask、所需背景、首个答案、下一步。找重复入口、只能靠历史记忆找到的页和失效状态；不新造泛用知识图谱。
2. 首页与 Study 第一层写研究什么、为什么、目前最重要的发现/未确定问题。事实来自现有数据或 D04，不把“在分析”改成“已证实”。
3. 新读者有背景→机制→结果的短路径；回访者看“哪些判断获得新证据”，不把每个 commit 都当科学进展。研究判断没变时如实说没变。
4. 用原上下文/URL 将任务传给 X783；无 context 的独立访问仍可用，不能自动退化成脱离任务的排行榜。
5. 为关键术语就地解释，为现有搜索加必要别名；不增加第二个搜索系统或强制引导流程。
6. 更新原 Reader Contract 的真实任务、选择器和下一步；不放宽预算、不堆满屏留白、不藏 caveat。

## 交付与验收

运行 audit:reader-contracts、现有导航/briefing/Study tests、build 和适用 UI 门。将冷读任务交 Q01；文字变少不等于理解变好。负例：缺上下文、历史 permalink、手机菜单、只知道 OpenEVO 名称、尚未完成的实验。
