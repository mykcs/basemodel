# 阅读任务单

这是一份供真实读者使用的任务单，不含答案。主持人提供两个匿名网站版本及访问顺序；请不要预先阅读实现说明、PR 描述或评分表。

## 开始

按主持人给出的 A、B 顺序分别完成任务。每个版本从指定入口开始，可以使用网站本身的导航、搜索、展开区和证据链接。请用自己的话回答，不要求记住内部代号。

第一次访问者从首页开始；实验室同伴从实验结果目录开始；几个月后回访者从实验目录开始。主持人提前确定你所属的一类，不记录姓名、邮箱或单位。

## 五个问题

1. 这个网站当前主要在研究什么问题？它为什么值得研究？
2. 选择一项实验，说出最重要的结果。你看到的数字衡量了什么？
3. 这项结果有哪些重要限制？哪些结论目前还不能下？
4. 研究者下一步准备解决什么问题？你会从哪里继续阅读或查证？
5. 找到支撑你所述结果的原始依据，记录你从入口到依据的访问路径。

## 记录

每个版本分别写下五个回答、访问的页面或段落、完成所用时间，以及一处让你犹豫或误解的地方。找不到或看不懂可以直接写“没有找到”或“没理解”，不需要猜答案。

不要把访问凭据、受保护链接中的临时参数、个人身份或服务器信息放入记录。

两个版本完成之前，主持人不提示正确答案、不指出哪个版本是新版。完成以后，才讨论哪些文字、图表或导航帮助了理解。
