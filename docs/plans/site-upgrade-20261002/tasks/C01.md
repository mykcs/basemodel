## 目标

像读论文一样理解对照，手机仍看得清单位和限制。借鉴 booktabs 的克制线条与分组，页面使用真实 HTML，不仿 PDF 截图。

已有 `src/components/common/MathFormula.astro`、KaTeX、研究组件原生 table、`src/styles/components/research-content-primitives.css`、`tests/e2e/sitewide-math-rendering.spec.ts`。

拟新增 `src/components/research/ScientificTable.astro` 及行为/浏览器 tests；创建前查同义 owner。CSS 初期 scoped，公共 token 交 A03。schema 不接管 D01/D03。

## 代码步骤

1. 从 X805 rank32 表与 X812 Final 表提取共同语义：题目、对象、单位、样本、评估角色、读数、限制。只共享真实重复，不造万能 TableBuilder。
2. 用 caption/thead/tbody/th scope；复杂表用 headers。数据可选择、复制，合适横线、分组与数字对齐替代彩色卡片。
3. raw value 与显示精度分离。未测/缺失/不适用不变0；不可比较时分组，不粗体捧出跨合同赢家；粗体也不表示统计显著。
4. 手机保留列关系；需要时局部有标签滚动区，支持键盘，不缩成蚂蚁字，不改成丢表头的卡片，sticky 列不能挡数据。
5. 复用 MathFormula 服务端渲染；公式附近解释符号与适用范围，长式局部滚动，可访问文本/MathML 与可复制 LaTeX 保留。
6. 同一数据构建期导出 CSV/LaTeX；转义 TeX 特殊字符，安全编码不受信 CSV 文本，区分正常负数与公式注入。

// 拟新增视图类型，非新的科学数据源。

## 交付与验收

两个真实调用方不复制数字；HTML/CSV/LaTeX raw 数值与缺失状态一致。列头、单位、分母及结论限制不隐藏。亮暗、390/768/1440、200% 放大、无 JS、打印、键盘可用，整页不横向溢出。

反例：同名指标不同单位、未知值、长中文、负数、上下标、CI 跨零、非劣未证明、CSV/TeX 特殊字符。测试组件格式化、现有数学渲染门及相关 UI；Q01 冷读确认没有把格式当统计结论。

## 排除与回退

不新增字体服务、不复制会议样式代码、不改科学分析。组件在两个实例不成立时保留简洁原生表也可，不为复用损害理解。逐调用方回退，原数据和来源不动。
