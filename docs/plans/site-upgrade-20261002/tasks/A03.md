3. 先迁移两个真实调用方再抽象；只是外观相似不够。科学格式化来自 D01/D03，不能嵌进 CSS 或重复 JSX。

5. 扩展现有 CSS audit，只拦新退化/真实 owner 错误；不加笼统总分。框架重大迁移若确有收益另走架构决策，本 PR 不迁移。
