共同边界：[COMMON](https://github.com/mykcs/basemodel/blob/docs/site-upgrade-program-20261002/docs/plans/site-upgrade-20261002/COMMON.md)。原规划会话仅授权计划；后续用户明确授权第二窗口逐项实施。本轮不合并、部署、访问最终评估题或启动新实验。

## 目标

把“看到几个数字”升级为知道哪些差异可靠、哪些无法比较、哪些关系值得下一步验证。网站不成为新的科学判决权威，所有派生结果必须可追到输入和分析代码。

## 已有与拟新增

已有研究 TS 快照、`public/research/seed-openevo/evidence/`、上游 source/analysis receipts 及已经冻结的 paired/bootstrap 定义。优先复用上游已验证配方；拟新增消费端 `scripts/research/analyze-evidence.py`、`src/lib/researchComparisons.ts` 与精确 fixture，只计算网站解释需要且现有 owner 未提供的派生量。

若某分析应由上游科学仓库持有，网站仅收版本化结果和 recipe 引用，不复制一套不同的统计口径。需要改变上游定义时列清独立科学变更，不在本 PR 静默替代。

## 比较合同（提议）

```ts
type ComparisonContract = {
  id: string; arms: string[];
  heldFixed: Record<string, string>; treatmentVariables: string[];
  evaluationRole: 'training' | 'development' | 'validation' | 'frozen_final';
  estimand: string; metricId: string; unit: string;
  pairingKeys: string[]; independentUnit: string;
  exclusionRule: string; aggregationRule: string;
  analysisRole: 'predeclared' | 'exploratory'; recipeRef: string;
};
```

不能要求所有字段完全相同而把真正的处理变量误判为不可比；也不能只因都叫 WebShop 就可比较。

## 实施步骤

1. 以 task panel、harness/prompt/decoding、模型/方法处理变量、预算、checkpoint lineage、评估角色建立合法比较集合。未知字段返回原因与 descriptive-only，不能自动进入排行榜。
2. 保留真实分析单位：rollout 总数不是独立样本数。相同 task 的多 rollout、跨轮重复 task、seed 与 continuation 相关结构要声明；配对/聚类/层级 bootstrap 按原科学合同执行，不把1024点当1024个独立人。
3. 冻结筛选、窗口、聚合、随机种子与处理缺失方式。报告有效 task/trial 数和排除/失败/缺测；不选择最好窗口、最好种子或只挑成功运行却不披露。
4. 分别复现三种解释所需结果：学习 loss 与 held-out outcome 的对应；rank32/128 容量—质量—exact 的取舍；β 训练后期窗口与冻结 Final 的不同角色。缺原始数据仅给报告精度与局限，不补造 CI。
5. 报效应大小/不确定性与样本范围；CI 跨零不证明等价。非劣性需预先指定容许差异和正确检验，不能事后挑界。多次探索窗口只标 exploratory，不冒充预注册确认。
6. 每个派生 JSON 记录 source hashes、recipe 版本、参数、输出精度和 exclusions；图表/正文只消费它。保留原始 published 数值，在新配方不同处解释差异，不覆盖历史。
7. 做纯离线重算，在固定输入下结果可复现。敏感轨迹留在授权域，只发布批准聚合。分析可以用现有 CPU/科学环境，不启动新训练或重新开启冻结评估题。

## 验收

三个研究问题各有“可比/不可比及理由”、输入清单、配方、可复现输出、支持与不支持的结论。与上游已有结果一致到其报告精度；更细精度必须有 raw 依据。

单测反例：32/64/128-task 混比、训练/Final 混合、模型是合法 treatment 却被拒、重复 rollout 当独立样本、无配对键、缺失当0、挑最好窗口、只有汇总无 raw 仍生成区间、CI 跨零写成等价。算术 fixture 有手工可核真值，随机重采样有固定种子和容差依据。

## 停止与回退

相关性只产生 D04 假设，不能自动写成机制证明。分析选择改变科学语义时停止该分支并提交判断请求，其余已批准分析继续。回退派生视图，不删 raw、不改旧冻结结论、不复用失配的绿色统计测试。
