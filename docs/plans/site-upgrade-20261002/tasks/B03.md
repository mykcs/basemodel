# B03 · 让更新、归档和复现说明长期可信

状态：已实施，等待本分支 exact-head Hosted CI 收口。工作量：M：lifecycle 合同、三类消费者和 revision-drift 审计。依赖：D01 PR 822 作为显式上游堆叠；B01 PR 817 作为合并顺序依赖。

共同边界：[COMMON](https://github.com/mykcs/basemodel/blob/docs/site-upgrade-program-20261002/docs/plans/site-upgrade-20261002/COMMON.md)。本任务已在用户后续明确指令下进入实现；仍未获得 merge、Vercel final gate、Production 部署、私有资产公开或新实验授权。

## 目标

防止几个月后“进行中/已结束”互相矛盾，或归档后找不到证据。归档服务历史理解，不能承诺移动目录就提速。

## 已有 owner 与数据边界

`src/content.config.ts`、`src/data/openEvoExperimentNavigation.ts`、`src/data/siteReaderContracts.ts`、`scripts/audit-freshness.ts`、`scripts/audit-claims.ts`、结果 note/appendix/protocol、Study/run/history/archive 实际页面。

研究元数据由 D01 负责。现有 changeEvents 只面向 model/paper/family，不能偷偷塞不兼容研究对象；需要扩展由 D01 唯一写入。

## 实施步骤

1. 分开实验状态、证据完整度、审阅时间、网站发布时间。重排 CSS 不等于刚采集新数据；冻结历史事实不因过30天自动变错。
2. 对 source revision 变化列出应复核的正文、导航、图表。构建不联网查服务器/W&B，只读已批准快照；更新为显式导入与提交。
3. 三类消费者分别落实：结果页显示证据范围；复现页有已验证环境/入口/预期输出/非公开资产说明；历史页解释当时为何那样判断、后来何种证据改变它。
4. 登记替代关系，保留 canonical、旧 URL、永久锚点。降低非活跃页入口优先级不等于删除负面实验或复制整篇内容。
5. 做真实作者路径：新增已批准结果→导入→修改正文引用→自动列出受影响导航/图→验收。减少修改位置，不新建编辑后台。
6. 修复确切失效状态并保留来源；没有实际复核不能自动更新“已检查”日期。

## 交付与验收

source 版本变化能触发恰当复核清单；同一实验的名称、状态、单位在 result/study/briefing/archive 一致。复现路径区分已验证和未知，缺权限不是文件不存在；至少一个历史判断可从现行页面回溯。

反例：改 CSS 更新实验时间、冻结事实误过期、未完成 run 变0分、当前链接到删页、私有 checkpoint 当匿名可下载。执行现有 freshness/claims/reader-contract audits 和相关 route tests。

## 范围/回退

不下载大 checkpoint、不做恢复验证、不重跑训练、不公开私有内容。现时证据拿不到时标范围，不自动续期。回退只撤销错误投影，不撤销已经证明的新结果；历史原件持续可追溯。
