## 目标

读者能看出差异、变化和证据限制，不只是看到几条漂亮曲线。W&B 原生交互是深入入口，网站正文不能依赖登录墙或外部服务。

已有 `src/components/research/WandbEvidencePanel.astro`、`public/research/seed-openevo/evidence/wandb-threeway/` 中 JSON/SVG/receipt、D3/ECharts、`src/styles/research-figure-readability.css`、`tests/e2e/canonical-research-figures.spec.ts`。

拟新增窄 `ResearchFigure.astro` 与按需交互入口（只有现有组件不能表达时建立）。不同时引入新图表库；静态摘要与动态视图使用 D03 的同一数据。

## 三种图形切片

训练趋势（轮次/真实步数/墙钟三者明确区分）；同合同对照差异（raw points/区间/样本）；容量—质量—成本取舍（不能把不可比实验串成前沿）。先在三个代表图上证明，再按 Q01 覆盖清单复用。

## 代码步骤

1. 清点已有静态图与 receipt，核对它们是否真正来自所标 W&B/run/文件。复用正确产物，不假设“没有 W&B 系统”。
2. 由冻结数据生成 SVG、可读表与摘要；轴、单位、分母、评估角色、聚合窗口明确，null 显示间断而不是0；不插值补缺来让曲线顺滑。
3. 交互仅用于真实任务：切 raw/平滑、显示区间、选择合法对照、查看某点。默认 raw 或明确标记的原合同聚合；平滑方法/窗口可见，不能改变底层分析。
4. 悬停信息也能通过键盘、点击/触屏和静态表获取；线型/标记/直接标注与颜色共同编码。图例切换不能悄悄改变 denominator、排序或比较资格。
5. 使用现有 D3/ECharts 中最小可行实现并接 A02 按需加载；无 JS/断第三方时 SVG、caption、数据表保留。宽图局部扩展，正文仍单列。
6. 继续沿用 W&B Report/Workspace 链接和访问状态说明。仅在已有公开授权且实际匿名访问通过时考虑嵌入；本 PR 不改变项目可见性、不带 token 到前端、不替换原始 run。
7. 图前写读图问题、图后写它支持与不支持的判断；B02 拥有论证文案，本线负责展示绑定与可读性，不自行强化结果。

## 验收与负例

同一事实在图、表、下载数据和正文一致；训练图不能标成 Final；不同 panel 不能无提示叠成赢家图。三种图均在390/768/1440、亮暗、键盘、触屏、减少动画、无 JS、打印可理解，无全页溢出。

负例：缺失步、resume 重复步、乱序、空曲线、同指标不同单位、错误平滑、隐藏失败 run、截断 y 轴不标记、32/64-panel 比较、W&B 不可访问。新增数据视图单测并执行 canonical-research-figures 与相关 UI 门。不能用截图“看着对”代替数值一致性。

## 回退

任何交互失败退回同源 SVG/表格，保留原生 W&B 链接；不回退原始证据、不撤掉 caveat。不把可视化失败变成研究数据消失。
