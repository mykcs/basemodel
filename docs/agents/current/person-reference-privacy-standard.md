# BaseModel 人物称谓与姓名隐私规范

状态：**现行、适用于整个仓库的可编辑内容及公开网站**。唯一规则 owner 为本文件；`AGENTS.md`、`docs/agents/README.md` 和 `src/AGENTS.md` 只负责把 Agents 引导到这里。适用科研沟通、申请材料、图表、标题、代码注释、测试和站点元数据。

## 唯一允许的私人关系称谓

| 人物 | 唯一公开称谓 | 使用场景 |
| --- | --- | --- |
| 科研沟通及申请所涉及的导师 | **W 老师** | 向导师的报告、谈话准备、科研评价及其相关页面 |
| 提出十个科研问题的前辈 | **L 学长** | 会议来源、十问、回应实验及其相关页面 |

**必须带空格，字母大写；不能省略 `L ` 只留下人物称谓，也不能把其他人映射成 W 或 L。** 任何未获此表授权的具体人物，一律用不暴露身份的功能角色描述（如“项目成员”“受访者”）；如果不知角色，先做不含个人身份的改写。不得公开真实姓名、姓氏加头衔、姓名缩写的可识别组合、与真实姓名等价的拼音、私人昵称或可反查的个人对话。

“教师模型”“项目导师”等一般角色并非个人专名；公开论文作者的正式学术引文、机构名称和模型名称属于不同类别，不能把正规引文静默改写成假作者。遇到不确定身份时先人工复核，不要猜测归属。

## 写入与发布检查

1. **写入前**：网页可见文案、标题、description/OG、图注、图片文字、文件名、测试期望、README、Agent/Dev/Wish/报告及引用链接均按上述规则匿名化。新材料不存放原始录音/逐字稿、未脱敏聊天、名单或联系方式。
2. **自动审查**：`npm run audit:person-privacy` 读取仓库源树中的文本（排除 `.git`、构建产物、依赖及二进制文件），对已知姓名／头衔及未冠以 `L ` 的特定称谓执行失败即停止的扫描。`npm run verify:deploy` 和 `npm run build` 均包含该审查；它能发现已知违规，**不能证明所有人名都被识别**。
3. **人工审查**：还要检查未知姓名、罗马化拼写、昵称、用户名、URL 路径、二维码、截图/PDF/视频、生成后的网页、外部链接的目标页面，以及 GitHub 的 Issue/PR/commit/Actions/部署记录。账户、W&B 实验路径或外部 RAW 链接可能间接识别人物；不能因为正文通过字符串测试就宣称完全匿名。
4. **来源真实性**：科研数值、实验来源和逐字证据不得伪造。历史封存记录保留原始测量；如其中保留旧标签，必须隔离为明确的历史证据，不作为当前网页文案。仅有三个明确的历史例外：`docs/agents/evidence/sitewide-typography/2026-10-22/source-disposition-ledger.json`（24 处旧版渲染文字取样）、`docs/evidence/project-report-sitewide-20261014/ROUTE_INVENTORY.json` 和 `docs/evidence/sitewide-fact-audit-20261019/ROUTE_INVENTORY.json`（各 1 处历史路由标题）。**例外只保留旧通用称谓，不放行真实姓名**。未来若要移走这些记录，按证据归档/恢复流程另行办理。
5. **历史边界**：修改当前分支不会抹去 Git 历史、PR diff、fork、外部缓存或已发布静态文件。若用户要求消除过去的可见痕迹，须单独做资产/身份审计并获得修改历史或仓库可见性的明确授权。

## 验收口径

当前公开 W&B 入口使用 `public/research/seed-openevo/evidence/source-index.json` 的匿名来源 ID。三份下载 JSON 明确标为展示副本，只隐藏列明的账号／访问定位字段；科研数值、run ID、source SHA、封存 artifact hash 和 authority 标记保留。索引记录原件 SHA-256、基线提交及科学 payload 承诺，单测拒绝测量字段漂移。原件已在本次任务的仅用户可读本地归档中逐字节保存并回读验 hash；该归档尚无远端灾难恢复认证，历史公开 Git 对象仍然存在。

`audit:person-privacy` 另外拒绝 `src/`、`public/` 中的直接 W&B 账号链接。全仓姓名检查与三个历史例外不变。图片解码、元数据检查与人工签字分别记录；现有 SVG 是分享 PNG 的可信原稿。逐路径风险及全部图片待人工验收清单见 [`EXPOSURE_INVENTORY.json`](../evidence/person-privacy/2026-10-29/EXPOSURE_INVENTORY.json)。该清单不等于全站或历史完全匿名。

- 当前可编辑正文和站点源码中，指上述两个人时分别只出现 **W 老师** / **L 学长**。
- 仓库文本没有已知真实姓名直接写法；以上三份封存取样/清单中的未冠名旧称谓是明确、非姓名的历史例外。
- `npm run audit:person-privacy` 通过，相关结构/页面测试通过，实际发布另需原有 exact-head CI、Vercel 与网页检查。
- 新增人物、新链接或图片都须人工审核；**测试通过 ≠ 全历史和外部链接完全脱敏**。
