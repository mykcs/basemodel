## 修复归属与主线整合

REPEAT-CORRECTION：触发为用户要求按既有标准检查残留文字，且生产页面仍复现案例 051。当前所有者是上述既有文字规范、能力页正文组件和 `tests/e2e/reader-journey.cases.ts`。已核查 5de1aeeb 的 949 个受 Git 管理文件及生产参数分析页；在独立 source export 修改，未覆盖共享工作区。允许操作为本清单内文案、所属字号、回归覆盖及审计记录。任何主线、正文或发布身份变化都使旧验收需要重新比对。

核查期间主线合入 #521（9bbae312），只改机制页导语与已有历史记录。本候选保留它新增的研究目的、模拟购物背景和购物示例入口，仅叠加本轮字号、实验状态标题和正文修复；保留它的历史记录。主线 9bbae312 与本轮改动共同组成待发布树。

该组合已通过完整 390 项浏览器检查，重试为 0。随后主线合入 #522（aa765005）的 CI 路由规划；保留其五个文件，重新验证确定性检查、预算回归和本批完整覆盖判定。页面源码与已通过的浏览器验收版本一致，最终发布身份在 PR 记录。

首次 Preview 的展开复查发现，第一轮页面的 7B/3B 节点和说明弹窗仍保留作者缩写。补齐这些说明：把动作失效、旧实验停止、新接口重新采集、参数组件数量与测试得分分别解释；参数几何的精确数字移到说明中并保留。原分支切换浏览器测试增加中文缩写反例与计数含义检查。修正版单独完成验收，旧版通过记录不作为修正版的通过凭据。
