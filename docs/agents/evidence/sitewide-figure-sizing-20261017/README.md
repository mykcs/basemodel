# 科研图表尺寸：全站清点与实施收据（2026-10-17）

**依据：** BaseModel 的 UI design principles；Project Report 规则 PR-P2-008 / PR-P2-009。

## 读者约定

BaseModel 是科研网站。论文 LaTeX / ICLR 的视觉启发只作用于真正承载科学证据的图、表和数学公式。普通正文、导航、工作台、设备状态及 16:9 演示页保留自身布局。

- **紧凑（单栏式）：** 一组置信区间、单个简单比较、列数少且内容简短的科学数据表。图可编辑、有刻度和解释；表使用语义 HTML / booktabs。
- **宽幅（跨双栏式）：** 多组不确定性、多面板曲线、并排方法结构、复杂 WebShop/Agent 工作流。宽度取决于真实信息量。
- 宽度是网站内部的**相对分级**，不要求正文排成双栏。手机保留重要证据，不造成整页横向滚动。数值、来源和科学结论均保持不变。

## 审计范围：全站而非单篇抽样

从当前 Astro 静态构建逐路由检查全部 **268** 个公开 HTML 页面：

| 核验维度 | 清点值 | 处置 |
| --- | ---: | --- |
| 构建路由 | 268 | 全部登记在 ROUTE_INVENTORY.json |
| 带 figure 的路由 | 26 | 逐个确认内容类型与布局责任 |
| 带 table 的路由 | 62 | 区分论文证据、参考资料、运营和导航 |
| 含以上任一元素的独立路由 | 66 | Chromium 390/1440px 实际 DOM 量测及页面溢出检查 |
| 静态 figure 标记 | 66 | 按语义分类 |
| 静态 table 标记 | 123 | 按角色判断，不把全部产品表格改成论文表 |
| 无静态 figure/table 的路由 | 202 | 不添加无意义科研风格或伪造图表 |

Papers 索引的源码还存在一个非活动模板表，浏览器 DOM 中的表格数量比静态标记少 1；两种统计范围不能混用。

## 宽度裁决

| 对象 | 处理 |
| --- | --- |
| L 学长十问 Q04/Q07/Q08 单组效果区间 | 默认 single：小图，约 38rem 上限 |
| Q04/Q07/Q09 多组配对结果 | 显式 double：宽图，约 55.625rem 上限 |
| SD-LoRA / Bounded 和 GPU 加速历史短量化表 | 内容紧凑的表按自然宽度呈现，不机械占满整行 |
| WebShop Results 两列观察表 | 自然宽度，长解释可换行 |
| 5–7 列消融、成组历史结果、密集任务归因 | 保留宽幅，窄屏表格局部滚动 |
| W&B 图截图、复杂模型机制、分支与因果流程 | 保留宽幅，轴标与依赖关系可读性优先 |
| SD-LoRA scaling 五个实测点与拟合图 | 保留宽幅：整体缩小其既有 SVG 会让轴标变得太小 |
| 固定 1280×720 briefing slides | 演示画布负责等比例缩放，不能从外面任意约束内部图宽 |
| Papers、Data Status、Lab、Workbench 的 UI 表格 | 保留产品组件和操作布局，不强制采用论文样式 |

完整分类与每条路由的 figure/table 数量记录在同目录的 ROUTE_INVENTORY.json；不在网页里发布这个工程验收表。

**科学事实：** 没有运行 GPU、WebShop 或修改冻结结果；视觉改造不改变任务题集、置信区间、分母和实验来源。

## 可复现验收

- 运行 node scripts/audit-sitewide-research-figure-widths.mjs 检查构建后的全部路由；新出现的未分类科研 figure 会触发失败。
- 使用脚本的 --snapshot 选项生成日期快照；快照只代表该次构建，不假称永久实时。
- Playwright 在实际生成页面检查宽度分级、手机/桌面溢出、明暗模式和科研信息保留；打印/灰度视图按受影响对象核实。
- 仓库事实门和静态构建门由 npm run verify:deploy 与 npm run build 负责。

> **覆盖边界：** HTML 清点覆盖静态可见构建；远端 W&B 交互及客户端运行时新生成的图由实际组件和证据 owner 单独验证，不能把静态扫描冒充这些运行时的科学验收。
