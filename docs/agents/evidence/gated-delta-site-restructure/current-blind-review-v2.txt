## Phase A｜冷读记录

以下仅依据两张截图，作为 Phase B 前的固定答案；未读取实现、历史偏好或其他材料，也未进入 Phase B。

**1. 5–10 秒内，这页在讲什么？**  
一项让 LoRA 在学习过程中持续更新的新研究设计：不再先训练候选、再决定是否采用，而是把更新状态直接放进 LoRA 参数里。第一印象是**研究方案说明，不是实验成果发布**。

**2. 注意力最先落在哪里？**  
桌面图首先是巨大的「Gated–Delta SD–LoRA」，随后是「我们之前做的本地 GDR–v1 放错了层级」。后一句比标题更有吸引力，因为它直接交代“之前哪里不对”。手机图也先看到标题，但后面的长段落明显更难扫读。

**3. 最重要的一个事实、结果或下一步是什么？**  
**第一版 D1 的设计已冻结，但正式实验尚未开始，不能据此说它比 Vanilla 更好。** 这是页面最值得带走的事实；其余内容主要解释为什么选这个设计。

**4. 哪处最像机器写作或汇报腔？为什么？**  
「因此现在能说的是……identity、State 位置和第一版 gate policy 已经收敛到一个可资格验证的 treatment」。这句话像内部验收报告：英文术语密集，“收敛到一个可资格验证的”又很抽象。读者需要自行翻译成“方案定了，检查过一些实现条件，效果还没验证”。

**5. 哪些术语迫使阅读停下来补上下文？**  
开头的 **GDR–v1、16 道题、Vanilla、DirectApply** 都默认读者知道前情；后面又出现 **OPSD、D0.13–D0.26、β、g**。尤其“State”：从原始规则里的状态走到 LoRA factors、再加入 AdamW memory，读者要自己辨认哪些是类比、哪些是实际存储和更新的对象。

**6. 是否有两个以上视觉中心争夺同等注意力？**  
没有明显的全页“双主标题”争抢，但正文里**彩框流程图与红色左边线的公式块**形成局部竞争，后面又重复一组彩框流程。截图中覆盖正文的小黑色浮动条也会抢注意力；手机图里，它还挡住了第一节标题的一部分。

**7. 科学边界有没有藏得太深，导致可见主张误导？**  
关键边界没有完全藏起来：开头就写了“正式实验还没有开始”“不能说明它比 Vanilla 更好”，结尾也再次强调。薄弱处是**标题不带“设计方案”或“待实验”状态，开头边界字号又偏小**；只扫标题和图的人可能误以为这已经是验证过的方法。

**8. 会删除、改名或下沉什么，同时保留意思？**  
把开头的状态提升为醒目的一句「方案已冻结，效果待实验」；将「Task Vector 退出 runtime causal path」改成「Task Vector 只做事后分析，不参与在线更新」。D0.xx 编号、checkpoint 和 qualification 细节下沉到研究证据里，正文保留“试过什么、发现什么、所以怎么改”。

**9. 有多想继续读？**  
**3/5。** “之前放错层级，现在换一种更新位置”提供了值得追下去的问题，但页面很快进入内部术语和证据编号，还没有正式结果作为阅读回报。桌面版尚能靠标题跳读；手机版把这些内容拉成很长的单列，更容易在四步推导中途退出。
