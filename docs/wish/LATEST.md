# 当前愿望

更新：2026-09-21

> **我希望 BaseModel 让一个几乎没有上下文的研究者——包括几个月后的我自己——能够很快理解一个研究问题为什么值得做、Base Model 和方法怎样影响实验、我们到底做了哪些实验、证据真正说明了什么、哪些东西还能复现，以及下一步应该继续研究什么。**

优先保护三件事：

- **先让人理解研究问题和结果，再让人读复杂细节。** 页面不是实验日志转储，也不是把所有证据同时摊开。
- **证据能被追溯，未知仍然是未知。** 网站可以帮助形成判断，但不能替科学 authority 补齐不存在的结果。
- **当前研究任务可以被明显突出。** 现在 SEED × OpenEVO 是主要研究线，因此网站可以围绕它组织大量页面；但 BaseModel 不应退化成只服务一组实验的临时报告站。

这个网站不应该变成模型排行榜、论文链接堆、供应商目录或漂亮的实验博客。它应该把模型知识、方法理解、复现实验、结果分析和证据边界连接成一个能帮助研究者形成可解释判断的研究工作台。
