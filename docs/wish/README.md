# BaseModel Wish

This folder stores BaseModel's **site-specific current product intent**.

Shared Wish lifecycle/versioning is owned centrally at:

https://github.com/mykcs/.agents/blob/main/docs/agents/WISH_PROTOCOL.md

Local files:

- `LATEST.md` — current BaseModel Wish;
- `DESIGN.md` — how that Wish maps to BaseModel's product/information architecture;
- `ARCHIVE.md` — superseded BaseModel Wishes and replacement reasons.

Do not copy the full cross-site Wish protocol back into this repository. BaseModel owns the current Wish content; `.agents` owns the shared Wish mechanism.
