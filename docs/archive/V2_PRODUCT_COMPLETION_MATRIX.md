## 2026-08-09 反证式补充验收

- [x] `REVISION-TRUTH`：模型固定版本只能来自带 `revision` 且明确支持 `reproducibility.model_revision` 的来源；发布日期不能充当 revision。
- [x] `PAPER-METHOD-BOUNDARY`：论文方法摘要不再读取 `model_selection.rationale`；缺少证据化摘要时显示待核验，研究范围单独由既有结构字段呈现。
- [x] `GLOBAL-QUICK-VIEW`：AppLayout 在非局部宿主页挂载全局 Quick View，按模型 ID 从静态 JSON endpoint 按需读取模型，不把整个模型详情目录序列化到每个页面。
- [x] `MODEL-UNKNOWN-HUMAN`：模型未知项使用 `fieldCatalog` 的人类可读字段名和研究影响解释，未知不被解释为“否”。
- [x] `REPLACEMENT-THREE-MODES`：替换候选同时给出严格复现、方法复现、现代化重跑三种确定性规则判断。
- [x] `MOBILE-COMPARE`：移动端不再依赖五列横向宽表，而使用按研究字段展开的模型比较卡，同时保留研究影响说明。
- [x] `FAMILY-HISTORY`：旧论文提示依据真正的非当前模型论文采用关系，而不是当前旗舰是否被论文使用。
- [x] `HARDWARE-COPY`：指南和模型详情都明确区分粗粒度目录档位、启发式显存规划与真实硬件实测。

## 原始目的复核

目标不是把页面做得更像数据库，而是让研究者能够定义严格复现/方法复现/现代化重跑任务，按资源、开放性、许可证、角色、证据和可复现性筛选模型，比较替换候选，保存可追溯决策，并把未知保留为未知。当前 GitHub → Cloudflare Pages 的静态优先交付已经覆盖这条研究决策路径；云端身份/协作和外部事实核验仍必须由真实服务与证据补齐。
