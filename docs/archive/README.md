# Documentation archive

This directory contains **historical evidence, not current instructions**.

The files here are retained because they explain earlier product milestones, plans, constraints, or research-workbench decisions. They are intentionally preserved close to their original form, so text inside an archived file may still call something “current”, refer to retired GitHub Pages / Cloudflare workflows, or point at paths that existed when the snapshot was written.

For current work, start from [`/AGENTS.md`](../../AGENTS.md), [`../agents/LATEST.md`](../agents/LATEST.md), and [`../agents/README.md`](../agents/README.md).

## Retained snapshots

- `V2_PRODUCT_COMPLETION_MATRIX.md`, `V2_COMPLETION_CHECKLIST.md`, `V2_ADVERSARIAL_ACCEPTANCE.md` — the V2 product closeout/acceptance snapshot from the earlier Research Decision Workbench phase.
- `backfill-plan-2026-08-06.md` — the August 6 model-catalog backfill plan; the file itself already declares that it is a historical baseline.
- `agent-context/` — the earlier V2 Research Workbench Agent context and its original entrypoint, retained for provenance.

## Rule for future archival

Archive a document when its main value is historical reconstruction rather than present-day execution. Do not move a still-authoritative current owner here merely because it has a date in its filename; first check whether source, tests, or current Agent routing still consume it.
