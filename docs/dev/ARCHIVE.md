# Superseded development directions

No earlier Dev generation is recorded. When this folder was introduced, current CI/provider decisions already lived in `docs/agents/current/`, and their earlier evidence remained under `docs/agents/history/`. Those files retain their existing roles rather than being recast as a former Dev version.

Add an entry here only after the current development direction materially changes. Record the period, prior choice, reason for replacement, and successor; keep transient run IDs and provider logs in their evidence records.
