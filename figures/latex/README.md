# LaTeX-native scientific figures in Astro

The BaseModel research website keeps **HTML as its reading and scientific-evidence owner**.
For static publication plots, use an **authoring-time** XeLaTeX / PGFPlots pipeline and
commit the resulting vector SVG. Astro renders it as a plain accessible `<img>`;
LaTeX, a charting library, and font files are **not** downloaded or executed in the browser.

## Q03: reproducible example

Authoritative values: `src/data/openEvoAdvisorTenQuestions.ts#ADVISOR_Q03_CUSTOM_PANEL`.
The sparse Q03 sequence contains **four measured checkpoints only**, not a full run.
TeX source: `figures/latex/q03-stage2-pgfplots.tex`.
Compiled asset: `public/research/seed-openevo/figures/q03-stage2-pgfplots.svg`.
Identity and expected four measurements: `q03-stage2-pgfplots.manifest.json`.

On a machine with XeLaTeX, PGFPlots 1.18, Liberation Serif and Inkscape installed:

```bash
bash scripts/rebuild-q03-pgfplot.sh
node scripts/verify-q03-pgfplot.mjs
```

The rebuild script prints SHA-256 values. Update the manifest hashes **only after**
viewing the PDF/SVG and comparing all four scores to the canonical TS dataset.
The ordinary Astro/Vercel build runs the verifier, not TeX, so deploys are fast
and deterministic. If a local TeX/Inkscape version changes generated bytes,
review the image before adopting the new hash rather than disabling the gate.

## Reusable scientific graphics grammar

- **Static, bounded curve:** PGFPlots source → PDF visual baseline → SVG with
  outlined glyphs → responsive Astro `PublicationPlot`. Keep captions and
  provenance links in HTML, not baked into the image.
- **Uncertainty / paired effects:** retain the confidence interval, zero line,
  sample size, comparator, estimate and exact numeric endpoints. Only migrate
  to generated vector figures after confirming the same scientific information
  remains available in accessible text.
- **Dense interactive workbench figures:** continue using semantic responsive
  SVG/HTML. A static image cannot replace zooming, selection, or screen reader
  access to actual values.
- **Research tables:** retain native `ResearchPaperTable` / `booktabs` and
  exact 4 × 3 cell values; a rasterized table is not an acceptable replacement.
- **Never interpolate missing runs as measurements.** Dashed lines between Q03
  saved points are visual connectors only; local y-axis 0–10 is not the actual
  task score denominator of 100. Do not conflate SEED's separate 128 tasks.

### Acceptance contract

For each migrated scientific plot: immutable source identity → data/TeX/SVG
checksum verification → real Chromium and WebKit screenshots at 390/768/1440
(light, dark, grayscale/print when relevant) → clipping and negative controls
→ exact-head Vercel Preview → main/Production verification. Test a real image,
not merely a metadata tag. Avoid changing the site's global typography branch
when repairing one source-bound plot.

## Why not runtime LaTeX?

Rendering a full TeX engine on every page load would add operational and
security burden without improving static plots. Astro can serve an SVG with
the PDF's actual vector geometry and outlined typography directly. This also
avoids downloading or distributing font files.
